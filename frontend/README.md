# 🎓 ASTU Smart: Frontend

This is the React-based frontend for the **ASTU Smart Complaint & Issue Tracking System**.

## 🚀 Features
- **Modern UI**: Implemented with Vanilla CSS and Glassmorphism.
- **Role-Based Views**: Specialized dashboards for Students, Staff, and Admins.
- **AI Chatbot**: Integrated RAG-based assistant for user support.
- **Interactive Analytics**: Data visualization using Recharts.

## 🛠 Tech Stack
- **Framework**: React.js (Vite)
- **Styling**: Vanilla CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Charts**: Recharts

## ⚡ Setup
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
